Quickstart

The API uses standard HTTP requests and returns JSON. No SDK or authentication token is required for the v1 endpoints documented here.

i

Configure your host first. Set apiBaseUrl in assets/config.js to the verified production API origin before using these examples.

Make a request

Request the first page of the feed:

cURL 
# Set this to your deployed API origin
API_BASE_URL="https://YOUR-API-HOST"

curl "$API_BASE_URL/api/v1/feed?page=1" \
  -H "Accept: application/json"

Read the response

A successful request returns JSON for the requested resource. See each endpoint for its parameters and response notes.

GET

Feed

Retrieve a paginated list of feed entries.

GET/api/v1/feed

Query parameters

ParameterTypeRequiredDescription
pageintegerNoPage number. Defaults to 1; accepted range is 1–30.

Example request

cURL 
curl "$API_BASE_URL/api/v1/feed?page=1"

Example response

Illustrative only. Verify exact response fields against your deployed API.

JSON 
{
  "data": [],
  "page": 1
}

GET

Search

Search available content using a query string.

GET/api/v1/search

Query parameters

ParameterTypeRequiredDescription
qstringYesSearch query. Maximum length: 200 characters.
pageintegerNoPage number. Defaults to 1; accepted range is 1–30.

Example request

cURL 
curl "$API_BASE_URL/api/v1/search?q=sample&page=1"

Video & media

A post may include media metadata and, when enrichment succeeds, a direct media URL.

embed_url

The embed or player page URL. It is not necessarily a direct media file.

video_url

The direct file URL when supplied by the source.

media[].url

A direct media URL available after successful best-effort enrichment.

i

Media enrichment is best-effort. A missing direct media URL does not necessarily mean the post failed to load.

Pagination

Feed and search endpoints accept a page query parameter.

  • Page numbering starts at 1.
  • The accepted page range is 1–30.
  • If omitted, the page defaults to 1.
  • Malformed or out-of-range values return a validation error.

Errors

Use the machine-readable error code to handle failures in your application.

invalid_pagePage is invalid or outside the supported range.
invalid_slugThe supplied slug is invalid.
missing_queryThe search query parameter is missing.
query_too_longThe query exceeds 200 characters.
not_foundThe requested resource could not be found.
method_not_allowedThe HTTP method is not supported for this route.
upstream_errorThe upstream service returned an error.
invalid_upstream_responseThe upstream response could not be parsed or validated.
upstream_timeoutThe upstream request timed out.
request_canceledThe request was canceled before completion.
internal_errorAn unexpected server error occurred.
